## 从仓库准备演示

在仓库根目录执行。初次安装和模型下载需要网络；本轮复验使用已有 Python 环境和本地模型，**没有重新创建虚拟环境或重新下载模型**。已验证的是从仓库原文重建独立数据库，不应称为全新电脑全流程安装验证。

```powershell
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements-vector.lock.txt
./.venv/Scripts/python.exe scripts/setup_vector.py

# 目标数据库必须不存在；脚本拒绝覆盖已有文件
./.venv/Scripts/python.exe scripts/prepare_demo.py --db .data/demo.sqlite3
./.venv/Scripts/python.exe -m skra --db .data/demo.sqlite3 index
./.venv/Scripts/python.exe scripts/demo.py --db .data/demo.sqlite3

# 离线复验；不会调用生成模型
./.venv/Scripts/python.exe -m unittest discover -s tests
./.venv/Scripts/python.exe -m skra --db .data/demo.sqlite3 eval --holdout examples/eval-holdout-cases.json --out .data/reproduced-holdout.json
```

模型 revision 固定为 `e8f8c211226b894fcb81acc59f3b34ba3efd5f42`。语料清单为 `examples/corpus/manifest.json`；语料文件固定 LF 换行以保持原始文件哈希。文件名中的 full 不代表全文，原文件已说明为选取、调整格式的节选。

演示默认不联网生成，但会保存本地运行记录、读取预算摘要。历史计费配置过期时只跳过离线预检回执；真实调用应传 `--live --config .data/model-config.json`，使用自行核对的有效配置与本机密钥。不得把历史 verified_at 改为今天来绕过核对。

## 当前实现边界与保留项

1. **产品入口**：普通 CLI 仅有 keyword/vector；BM25、RRF、bounded_answer 是 Python 与实验接口。CLI 集成属于后续功能，不在此次收尾中追加。
2. **切分能力**：Markdown 默认基线，结构策略须显式选择。指南策略并非语义段落解析器，只在 20 行阈值处对冒号紧接列表作有限连接；步骤策略保留完整代码围栏，但跨空行的前提、步骤和警告不保证同块。PDF 不支持 OCR、复杂表格或双栏重建。
3. **评测预算**：对照固定 top-k=5，没有强制统一总 token 上限；token 用字符数/4 估算。这是相对 PRD 理想评测要求的明确未实现项，不能称为“同等总上下文预算对照”。本轮保留历史评测定义，未重写指标。
4. **元数据**：仍可能进入检索结果；关键词只在同分时优先正文，向量未过滤元数据。不能宣称元数据绝不占用正文名额。
5. **生成与语义**：逐字引用、版本与结构校验不保证推理支持或翻译准确。Q06 的 partial、H03/H04/H09 的检索缺口继续保留；小样本不能推导整体准确率。
6. **补充检索**：最多两轮，不做自主查询改写或联网研究。deadline 是同步步骤边界的协作式检查，不能中断正在执行的回调；生成仍使用原有单请求网络超时。无新证据不再生成。
7. **费用未知**：仍保留预留并阻止后续请求，没有自动核销产品界面；不能宣称实现了完整计费平台。
8. **工程交付**：本轮修改及证据保存在本地工作区，没有执行 Git 提交、推送、打发布标签或部署。历史证据中的旧声明以本文件更正为准。

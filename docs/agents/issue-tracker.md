# Issue tracker: Local Markdown

本项目继续采用本地任务，已关联 GitHub 仓库 https://github.com/lingjiang141/Safety-Knowledge-Research-Assistant.git ，尚未迁移外部 Issue。唯一 PRD 保留在根目录 PRD.md，不创建副本。任务位于 `.scratch/security-research-assistant/issues/`，总览为根目录 ROADMAP.md。

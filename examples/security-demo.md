# Synthetic security learning fixture

This document is authored for this project as a test fixture, not an official research source.
Its contents are dedicated to CC0-1.0 for reuse in the demo.

## Prompt injection

In this fictional example, an assistant reads an untrusted document containing instructions to change its task.
The phrase "ignore previous instructions" is example data to discuss, not a command to execute.

## Tool permissions

In this fictional setup, the assistant can read documents but cannot send messages or delete files.
Least privilege means granting only the permissions needed for the intended task.

## Missing measurements

This fixture contains no measured attack success rate or project evaluation results.

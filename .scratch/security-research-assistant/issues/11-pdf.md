# 11 — 导入文本型 PDF 并按页核对回答

## What to build

扩展既有导入到问答路径，使文本型 PDF 的回答可追溯到正确页码和原文片段。

新增重点：文本型报告中的章节/段落恢复、跨页连续段落、重复页眉页脚处理，以及无法可靠提取时的显式回退。不要以 PDF 扩展名自动决定语义切分，沿用内容块策略。

## Acceptance criteria

- [ ] 正文与重复页眉页脚分离，保留原页坐标或可复核定位；重复正文不得误删。
- [ ] 多页报告可展示章节路径、原文定位与切分预览；阅读顺序混乱、复杂表格等明确提示不支持，不隐性丢失内容。
- [ ] 使用 TDD 覆盖跨页段落、页眉正文同词、策略变更和提取失败；附实际页面对照。


- [ ] 保存原文件 hash、来源、许可和提取版本，页码定义明确。
- [ ] CLI 展示页码及原文；沿用同一版本、预算与引用校验机制。
- [ ] 扫描件无正文、损坏文件和明显提取异常给出失败原因，不自动 OCR 或伪装成功。
- [ ] 自建多页样例验证跨页定位及更新删除，真实 PDF 样例完成检索到引用演示。

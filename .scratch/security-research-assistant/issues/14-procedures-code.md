## What to build

在操作指南和含代码的 Markdown 中查询某一步，返回该步骤及必要前提、代码和相邻警告的可定位证据；只分析代码，不执行。

## Acceptance criteria

- [x] 支持编号步骤、前置条件、围栏代码块和警告段的结构关联；与说明性段落允许混合，不能仅按文件类型路由。
- [x] 短代码块保持完整；超长代码块不得绕过 token 上限，按行拆分、保留连续范围及父块关系并提示不完整。
- [x] 检索命中子片段后，在明确证据 token 预算内扩展必要父级或相邻块；每个不连续原文跨度单独引用。
- [x] 前提未提供时不能补造；清楚区分原文引用与为阅读补充的标题上下文。
- [x] 用 TDD 覆盖前提和步骤跨块、代码围栏含标题符号、警告在相邻段、预算不足和注入示例不执行。
- [x] CLI 查询与回答证据路径可演示，记录资料/策略/模型版本；真实生成未运行则标记，不冒用模拟结果。

# 06 — 更新和删除资料后阻止旧证据进入新回答

Status: needs-triage
State: open
Type: AFK
Milestone: M1
User stories: US2, US14, US15, US16
Source: [PRD](../../../PRD.md)

## What to build

执行要求：开始实现前直接调用 tdd 技能；具体行为优先级见 docs/development-workflow.md。用户已授权。

通过管理 CLI 更新或删除资料，贯通有效版本发布、检索过滤、回答前复核及历史引用提示。

## Acceptance criteria

- [ ] 同版本同配置片段标识稳定，新版本不复用旧标识指向不同文本。
- [ ] 构建失败不发布半成品；切换后检索不返回旧内容，删除后新回答不可引用已删除片段。
- [ ] 回答生成期间更新或删除证据时阻止过时答案并提示重新查询。
- [ ] 历史引用保留版本与失效提示；程序强制限制管理操作，不授予回答模型写入工具。
- [ ] 完整测试新增、重复导入、修改、删除、失败恢复与回答期间变更场景。

# 13 — 按指南结构切分并展示完整证据

Status: needs-triage
State: open
Type: AFK

User stories: US24, US27, US28
Source: [PRD](../../../PRD.md)

## What to build

将标题、段落、列表识别为可定位的内容块；导入结构化安全指南后，用原有向量检索查询定义或防护建议，返回带标题路径的完整证据。

## Acceptance criteria

- [ ] 保留现有 heading-lines-v1:20 作为固定基线；新增显式策略标识、版本及选择理由，支持人工覆盖。
- [ ] 说明性元数据与正文区分；来源、许可不丢失，但不默认作为正文候选挤占检索名额；不能仅靠关键词删除含义相近的正文。
- [ ] 标题路径补充到检索表示，但引用只来自真实原文跨度；不把补充上下文伪装为逐字引文。
- [ ] 定义与限定语、列表引导句与列表项尽量共存；超预算时按块边界拆分并保留父块关联，不静默截断。
- [ ] CLI 导入→索引→中文查询→证据展示可复现；重复导入与策略变更后的版本失效通过 TDD 测试。
- [ ] 准备正常、混合结构、结构不明三类样例；结构不明回退通用策略并记录原因，不猜成高置信分类。

# 09 — 评估重排序是否值得加入回答流程

Status: needs-triage
State: open
Type: AFK
Milestone: M2
User stories: US18, US19, US21
Source: [PRD](../../../PRD.md)

## What to build

开展可选重排序实验，比较同一候选集上的质量、延迟和费用，以证据决定保留或不采用。

## Acceptance criteria

- [ ] 优先本地实现，候选数和参数显式记录；不改变其他检索或生成因素。
- [ ] 开关可控制，原方案可复现；回归版本过滤与引用映射。
- [ ] 产出实际对照结果与取舍；只有真实实验支持时才能写“无收益而不采用”。
- [ ] 无资源或额度不能实验时标记延期及原因，不能记为实验完成；此可选任务不阻塞后续必做功能。

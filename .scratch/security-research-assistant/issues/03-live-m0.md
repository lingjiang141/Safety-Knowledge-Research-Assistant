# 03 — 验证 DeepSeek 真实调用和三类回答

Status: needs-info
State: blocked
Type: HITL
Milestone: M0
User stories: US4, US6, US7, US11, US12, US19, US20
Source: [PRD](../../../PRD.md)

## What to build

核对官方模型与价格，由用户在本机配置密钥，在现有 10 元总预算内演示有依据、无依据和部分有依据的问答。

## Acceptance criteria

- [ ] 代码与本地测试先完成，人工仅提供本机密钥配置及参与真实答案复核；不在聊天收集密钥。
- [ ] 确认价格计费单位、输入输出上限和预留算法；请求前可查看累计费用与预计最大费用。
- [ ] 三类问题分别表现为有据回答、说明缺失、先回答有据部分；人工核查引用支持及释义准确性。
- [ ] 验证 API 错误展示；保存真实输出与费用，账单未确认部分单独标注。
- [ ] 提供 M0 演示命令和实际结果；密钥或额度缺失时保留未完成状态，不用模拟结果关单。
